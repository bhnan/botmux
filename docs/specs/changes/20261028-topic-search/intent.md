# Intent：话题聚合检索增强

- 阶段：一期。
- 日期：2026-10-29。
- 代码基线：`fc5b44746`。
- 规格：[spec.md](./spec.md)；计划：[plan.md](./plan.md)。

## 1. 需求

在现有 Dashboard 话题聚合页面快速找回讨论。一个话题可包含多个 session，搜索以话题为结果单位。

现有页面通过 `SessionTopicGroup` 聚合 session，使用 `sessionSearchText` 包含匹配过滤。新增持久化 Topic、事件摘要、关键词及可选 embedding，提升话题内容的可检索性。

## 2. 目标

| ID | 目标 |
|---|---|
| I-01 | 兼容现有 topicKey、话题分组、session 展示和打开入口。 |
| I-02 | 持久保存 Topic、事件摘要数组、关键词和可选向量。 |
| I-03 | 按配置时间后台检查话题，有新增消息才生成摘要。 |
| I-04 | 基于旧摘要与新增消息执行 add/update/noop，保存成功处理游标。 |
| I-05 | 为现有话题聚合页面提供统一检索 API，沿用 Dashboard 认证与访问范围。 |
| I-06 | 独立配置摘要 LLM；embedding 可选，默认关闭。 |
| I-07 | 展示命中摘要、来源、覆盖范围和更新时间；支持历史结果分页。 |
| I-08 | 业务集中在 src/topic/，复用现有 Dashboard 宿主与端口。 |

## 3. 一期交付

- `src/types.ts` 中与 Session 并列的 Topic、TopicSummary。
- 已知飞书 thread 话题的持久目录与定时增量整理。
- 一次结构化 LLM 调用生成摘要变更和关键词。
- 关键词检索、可选向量检索与融合排序。
- Dashboard 话题聚合页面接入，保留现有分组、展开和导航能力。
- 配置、失败恢复和运行状态。

## 4. 一期不做

- Bot/Agent 跨话题检索入口及其授权体系。
- 检索 CLI、Skill、MCP 和外部服务接入。
- 新增监听端口、独立进程、独立管理页面。
- 全文检索、附件解析、全租户话题发现。
- 用户反馈学习、手动摘要编辑、专职摘要 Bot。
- 消息事件触发整理、向话题自动发送总结。
- Session 生命周期和聊天模型改造。

## 5. 更新与成本

定时扫描使用成功处理游标判断增量。无新增消息跳过模型；有新增消息时结合相关旧摘要更新。摘要、关键词、游标一起提交。仅新增或正文变化的摘要生成向量，失败向量独立重试。

页面检索使用 Dashboard 用户上下文，不以某个 Bot 是否参与话题作为查询条件。后台读取由可访问源消息的 daemon 执行。

## 6. 验收方向

按话题去重、兼容现有聚合页面、增量更新正确、模型关闭与故障降级可用。用固定查询集评估 Top-3 命中率、响应时间及模型调用量，具体条件见 spec。
